CALIBRATION NOTES

To Adjust Steering Sensitivity

  1. Change LANE_DEVIATION_DEADZONE (default 10px)
    • Increase (15-20px): less sensitive, more stable
    • Decrease (5-7px): more responsive, may oscillate
  2. Change LANE_DEVIATION_MAX (default 50px)
    • Match with your camera ROI width
    • Formula: ROI_WIDTH / 2 × 0.5-0.7

To Tune Speed Control

  1. Update esc_speed_table[] with your vehicle's measured data
  2. Test on flat ground, measure actual speed at each ESC angle
  3. Adjust PID gains if overshoot/undershoot occurs

To Change Feedback Rate

Current: 10Hz (100ms) synchronized with speed calculation

If you want faster feedback:

  1. Change FEEDBACK_SEND_INTERVAL_MS to 50ms (20Hz)
  2. Change SPEED_CALC_INTERVAL_MS to 50ms as well
  3. Update MiniPC serial_esp32.cpp line 135 to match

UPLOAD INSTRUCTIONS
  1. Open Arduino IDE or PlatformIO
  2. Select board: ESP32S3 Dev Module
  3. Select port: (your COM port)
  4. Upload autonomous_REFACTORED.ino
  5. Open Serial Monitor at 230400 baud
  6. Verify output shows system ready
